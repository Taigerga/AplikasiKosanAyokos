# ANALISIS CLOUD COMPUTING

Berdasarkan source code yang ditemukan, jelaskan:

## Konsep Sistem

* Tujuan aplikasi
* Permasalahan yang diselesaikan
* Target pengguna
* Alur bisnis utama

## SaaS Analysis

Analisis apakah sistem dapat dikategorikan sebagai SaaS.

Jelaskan:

* Alasan
* Karakteristik SaaS yang terpenuhi
* Cara pengguna menggunakan layanan
* Keuntungan model SaaS

## Cloud Computing Characteristics

Hubungkan sistem dengan:

* On-demand Self Service
* Broad Network Access
* Resource Pooling
* Rapid Elasticity
* Measured Service

Jelaskan masing-masing secara rinci.

## Service Model

Analisis hubungan sistem dengan:

* SaaS
* PaaS
* IaaS

## Deployment Model

Analisis kemungkinan implementasi pada:

* Public Cloud
* Private Cloud
* Hybrid Cloud

Tentukan model yang paling sesuai.

## Security Analysis

Analisis implementasi:

* Authentication
* Authorization
* Session Management
* Validation
* Middleware
* CSRF Protection

## Scalability Analysis

Jelaskan bagaimana sistem dapat dikembangkan untuk:

* 100 pengguna
* 1.000 pengguna
* 10.000 pengguna

Sertakan rekomendasi:

* Load Balancer
* Caching
* Queue
* Database Optimization
* CDN
